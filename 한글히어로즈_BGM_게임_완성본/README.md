# 한글 히어로즈 · BGM 통합 게임

## 음악 연결
- `public/assets/menu.mp3`: Kingdom_s_First_Light.mp3 — 첫 화면 및 게임 선택 화면
- `public/assets/game.mp3`: Letters_in_the_Tall_Grass.mp3 — 모든 학습 게임과 멀티플레이 게임 진행 중
- 화면 전환 시 음악 자동 전환, 반복 재생. 브라우저 자동재생 정책 때문에 최초 버튼 클릭 후 음악이 시작됩니다. 오른쪽 위 음소거 버튼 사용.

## 구성
- 첫 화면 저학년/고학년 선택
- 4가지 개인 연습 게임: 글자 블록, 맞춤법 배틀, 문장 미로, 어휘 마을
- 코드를 이용한 학급 멀티플레이 맞춤법 대결: Cloudflare Workers + Durable Objects
- 이미지 배경·정답/오답 이펙트·점수·진행바
- 개인 연습 모드는 서버 없이 오프라인 HTML로도 실행할 수 있으나, 방 코드는 Cloudflare 배포가 필요합니다.

## 실행
Node.js 설치 후 프로젝트 폴더에서:
```bash
npm install
npm run dev
```
터미널에 나온 로컬 주소로 접속. 배포는 `npx wrangler login` 후 `npm run deploy`.

## 유의
개발 및 교사 테스트용 시제품으로, 실제 배포 및 500명 부하 테스트는 수행하지 않았습니다. 멀티플레이 서버는 예시 맞춤법 12개 중 10개 문제를 사용합니다. 개인 게임의 문제도 시범용이므로 학습 내용 검수와 문항 확장이 필요합니다. 아동 개인정보 보호를 위해 별명 사용을 권장하며, 교사 인증 및 재접속 복구 기능은 추가 개발 대상입니다.
